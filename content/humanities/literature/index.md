## 🎯 文学核心概念

### 文学性

```
文学性的构成：
1. 语言：形象、含蓄、多义
2. 结构：叙事、节奏、张力
3. 意象：象征、隐喻、暗示
4. 情感：共鸣、感染、升华
```

## 🎯 核心结论

### 文学的基本发现

1. **文学是建构的**：意义由读者参与建构
2. **文学是审美的**：形式与内容统一
3. **文学是多元的**：多种解读并存
4. **文学是历史的**：受时代影响
5. **文学是跨文化的**：人类共同遗产

### 文学学习路径

```
文学学习四步骤：
1. 阅读经典：积累文本经验
2. 学习理论：掌握分析工具
3. 批评实践：培养鉴赏能力
4. 创作尝试：理解创作过程
```
