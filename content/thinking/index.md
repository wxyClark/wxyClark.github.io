# 思维科学知识体系

> **第一性原理**：思维科学是研究人类思维活动规律的科学，从认知过程到创造性思维，探索人类大脑的运作机制。

---

## 📚 思维科学的公理体系

### 第一性原理：思维可训练性

```
思维科学的基本信念：
1. 思维遵循一定的规律
2. 思维可以通过训练提升
3. 不同的思维模式适用于不同问题
4. 思维受认知偏差的影响
```
