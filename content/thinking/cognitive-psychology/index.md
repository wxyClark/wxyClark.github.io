# 认知心理

> **心理学的主目录在 [社会科学/心理学](../../social-sciences/psychology/index.md)**，那里讲情绪、人格、异常心理。本页只讲一个更窄、但更能立刻改变你做事方式的问题：**大脑处理信息的带宽到底有多少，怎么用才不浪费。**

---

## 🎯 这个视角独有的 20%

| 你遇到的困惑 | 认知科学的答案 | 马上能改的动作 |
|--------------|----------------|----------------|
| 一边看资料一边回消息，为什么半天没进展 | 注意是**单线程**的，切换有重建成本 | 一次只开一个窗口，批量处理消息 |
| 看懂了，合上书就说不出来 | **流畅感 ≠ 记住了**，识别和提取是两条路 | 合上书口述一遍，卡住的地方才是真漏洞 |
| 学了新东西总是接不上旧的 | 新知识必须**挂钩**到已有图式 | 先问「这像我已知的什么」，再记细节 |
| 复杂问题一想就晕 | 工作记忆只能同时抓 **4 个左右组块** | 把问题写下来外化，纸上不占内存 |
| 明明很努力却学不会 | 认知负荷被**无关信息**吃掉了 | 先清掉花哨格式、无关例子、多余步骤 |

## 🧠 一条链路：信息只有四个关口

```mermaid
graph LR
    A["感觉登记<br/>几百毫秒"] --> B["注意<br/>决定谁进来"]
    B --> C["工作记忆<br/>4 个组块"]
    C --> D["长时记忆<br/>靠复述与关联"]
    D -->|"提取练习"| C
    style B fill:#e3f2fd
    style C fill:#fff3e0
```

四个关口都可以被人为卡住，也都各有对应的破解办法：

| 关口 | 卡在哪 | 破解 |
|------|--------|------|
| 感觉登记 | 信息太多，根本进不来 | 减少输入源：关通知、单一任务 |
| 注意 | 被新异刺激劫持 | 把「想做的事」写在纸上，减少头脑搜索 |
| 工作记忆 | 一次抓太多概念 | 组块化：先记结构，再填细节 |
| 长时记忆 | 只存不取，越存越乱 | 间隔重复 + 提取练习，而不是重读 |

---

## ⚠️ 三个最常见的误解

**1. "我记性差"其实是"我没检索过"**
记忆问题 80% 出在**提取**而不是存储。反复重读制造的是熟悉感，不是可调用性。

**2. "专注力不够"往往是"任务没拆"**
一个模糊的大任务会让工作记忆持续空转（我该从哪开始？），拆成下一个具体动作，注意力自然回来。

**3. "多任务并行效率高"是错觉**
切换不是免费的，每次切回都要重新加载上下文；看起来忙，实际总产出更低。
