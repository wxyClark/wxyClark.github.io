# 法律常识 — 保护自己的必备知识

> 90%的人不了解基本法律常识，导致权益受损时无法有效维权
> 目标：掌握日常生活中最实用的法律知识，避免踩坑

---

## 一、劳动法核心知识

### 1.1 劳动合同要点

```mermaid
flowchart TB
    A["入职"] --> B{"签合同"}
    B -->|"签了"| C["保留副本"]
    B -->|"未签"| D["要求补签"]
    
    C --> E["合同到期前30天"]
    E --> F["续签或终止"]
    
    D --> G["仲裁维权"]
    
    style A fill:#e3f2fd
    style C fill:#e8f5e9
    style G fill:#ffebee
```

### 1.2 劳动权益对照表

| 情况 | 外行做法 | 内行做法 |
|------|----------|----------|
| 未签合同 | 继续工作 | 要求双倍工资赔偿 |
| 试用期过长 | 忍着 | 仲裁要求补偿 |
| 加班无加班费 | 不敢要 | 收集证据仲裁 |
| 被辞退无补偿 | 自认倒霉 | 要求N+1补偿 |
| 社保未缴纳 | 不在乎 | 要求补缴或赔偿 |

### 1.3 离职注意事项

| 场景 | 外行做法 | 内行做法 |
|------|----------|----------|
| 主动辞职 | 随时走 | 提前30天书面通知 |
| 被辞退 | 签字走人 | 确认补偿方案 |
| 协商离职 | 接受口头承诺 | 签订书面协议 |
| 离职证明 | 不在意 | 要求开具 |
| 社保转移 | 不处理 | 及时转移 |

## 二、合同法基础

### 2.1 合同签订要点

```mermaid
flowchart TB
    A["合同签订"] --> B["主体审查"]
    A --> C["条款审查"]
    A --> D["签字盖章"]
    
    B --> B1["对方资质"]
    B --> B2["履约能力"]
    
    C --> C1["权利义务"]
    C --> C2["违约责任"]
    C --> C3["争议解决"]
    
    D --> D1["签字+日期"]
    D --> D2["骑缝章"]
    D --> D3["保留原件"]
    
    style A fill:#e3f2fd
    style B fill:#fff3e0
    style C fill:#e8f5e9
    style D fill:#f3e5f5
```

### 2.2 常见合同陷阱

| 陷阱类型 | 外行做法 | 内行做法 |
|----------|----------|----------|
| 阴阳合同 | 只看一份 | 核对所有版本 |
| 模糊条款 | 不在意 | 要求明确具体 |
| 不平等条款 | 接受 | 协商修改或拒签 |
| 缺少违约条款 | 不关注 | 明确违约责任 |
| 口头承诺 | 相信 | 要求写入合同 |

## 四、借贷法律知识

### 4.1 借贷风险防范

```mermaid
flowchart TB
    A["借贷关系"] --> B{"有无借条"}
    B -->|"有"| C["保留证据"]
    B -->|"无"| D["立即补签"]
    
    C --> E["约定还款时间"]
    E --> F["到期催收"]
    F --> G{"不还"}
    G -->|"是"| H["法律途径"]
    
    D --> I["证明借贷关系"]
    
    style A fill:#e3f2fd
    style C fill:#e8f5e9
    style H fill:#ffebee
```

### 4.2 借条模板要点

```
借条

今借到[出借人姓名]人民币[大写金额]元整（¥[数字金额]元），
用于[借款用途]，借款期限为[起止日期]，
年利率为[利率]%，到期一次性还本付息。

如逾期未还，借款人愿承担出借人为实现债权所支付的
诉讼费、律师费、交通费等费用。

借款人：[签字+手印]
身份证号：[号码]
联系电话：[号码]
日期：[年月日]
```

### 4.3 利率红线

| 情况 | 利率标准 | 法律效力 |
|------|----------|----------|
| 年利率<24% | 合法 | 受法律保护 |
| 24%-36% | 自然债务 | 已付不退，未付不追 |
| >36% | 无效 | 无效，可要求返还 |

## 七、法律避坑指南

### 7.1 常见法律误区

```mermaid
mindmap
  root((法律误区))
    劳动
      试用期不用签合同
      加班费可以放弃
      离职无补偿
    消费
      买假货自认倒霉
      维权太麻烦
      诉讼费太高
    借贷
      朋友借钱不好意思要借条
      口头约定有效
      利率随便约定
    婚姻
      婚前财产婚后自动共有
      彩礼必须返还
      孩子抚养权一定归母亲
```

### 7.2 证据意识

| 场景 | 外行做法 | 内行做法 |
|------|----------|----------|
| 纠纷发生 | 口头争论 | 书面记录 |
| 对方承诺 | 口头相信 | 录音/书面确认 |
| 损失发生 | 不记录 | 拍照+保留凭证 |
| 沟通记录 | 不保存 | 截图+备份 |
