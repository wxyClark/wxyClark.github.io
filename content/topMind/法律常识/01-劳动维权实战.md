# 劳动维权实战 — 保护自己的劳动权益

> 90%的劳动者不了解自己的权益，导致利益受损

---

## 一、劳动合同要点

### 1.1 签订合同检查清单

```mermaid
flowchart TB
    A["合同检查"] --> B["基本信息"]
    A --> C["工作内容"]
    A --> D["薪酬待遇"]
    A --> E["合同期限"]
    
    B --> B1["双方信息完整"]
    B --> B2["签字盖章"]
    
    C --> C1["岗位明确"]
    C --> C2["工作地点"]
    
    D --> D1["基本工资"]
    D --> D2["绩效奖金"]
    D --> D3["五险一金"]
    
    E --> E1["起止日期"]
    E --> E2["试用期"]
    
    style A fill:#e3f2fd
    style B fill:#fff3e0
    style C fill:#e8f5e9
    style D fill:#f3e5f5
    style E fill:#fce4ec
```

### 1.2 合同陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| 未签合同 | 试用期不签 | 要求双倍工资 |
| 试用期过长 | 超过法定期限 | 仲裁维权 |
| 薪资模糊 | 不写具体金额 | 要求明确 |
| 竞业限制 | 无补偿金 | 协商修改 |

## 二、离职权益

### 2.1 离职补偿标准

```mermaid
flowchart TB
    A["离职类型"] --> B["主动辞职"]
    A --> C["被辞退"]
    A --> D["协商离职"]
    
    B --> B1["无补偿"]
    B --> B2["提前30天通知"]
    
    C --> C1["N+1补偿"]
    C --> C2["违法辞退2N"]
    
    D --> D1["协商金额"]
    D --> D2["书面协议"]
    
    style A fill:#e3f2fd
    style B fill:#e8f5e9
    style C fill:#ffebee
    style D fill:#fff3e0
```

### 2.2 补偿计算

| 情况 | 补偿标准 | 说明 |
|------|----------|------|
| 合法辞退 | N+1 | N=工作年限 |
| 违法辞退 | 2N | 2倍赔偿 |
| 协商离职 | 协商金额 | 书面协议 |
| 主动辞职 | 无 | 提前30天 |

## 三、加班权益

### 3.1 加班费标准

| 类型 | 标准 | 说明 |
|------|------|------|
| 工作日加班 | 1.5倍 | 平日延长 |
| 周末加班 | 2倍 | 休息日 |
| 法定节假日 | 3倍 | 带薪假期 |

### 3.2 加班维权

- [ ] 保留加班记录
- [ ] 保留考勤记录
- [ ] 保留工作沟通记录
- [ ] 向劳动监察投诉
- [ ] 申请劳动仲裁

### 4.2 社保维权

- 单位未缴社保：可要求补缴
- 未缴社保：可被迫离职并要求补偿
- 投诉渠道：12333、劳动监察

## 六、行动清单

### 入职时

- [ ] 签订正式劳动合同
- [ ] 保留合同副本
- [ ] 确认薪资待遇
- [ ] 确认社保缴纳

### 工作中

- [ ] 保留工作记录
- [ ] 保留考勤记录
- [ ] 保留沟通记录
- [ ] 了解自己的权益

### 离职时

- [ ] 确认补偿方案
- [ ] 签订书面协议
- [ ] 办理离职手续
- [ ] 转移社保关系
