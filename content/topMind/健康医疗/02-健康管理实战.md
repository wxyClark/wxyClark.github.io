## 一、睡眠优化

### 1.1 睡眠质量公式

```
睡眠质量 = 时长 × 深度 × 规律性
```

### 1.2 睡眠优化方法

```mermaid
flowchart TB
    A["睡眠优化"] --> B["环境优化"]
    A --> C["时间管理"]
    A --> D["习惯养成"]
    
    B --> B1["黑暗"]
    B --> B2["安静"]
    B --> B3["凉爽"]
    
    C --> C1["固定作息"]
    C --> C2["睡前放松"]
    C --> C3["避免刺激"]
    
    D --> D1["睡前1小时不看手机"]
    D --> D2["睡前不喝茶/咖啡"]
    D --> D3["周末不睡懒觉"]
    
    style A fill:#e3f2fd
    style B fill:#fff3e0
    style C fill:#e8f5e9
    style D fill:#f3e5f5
```

### 1.3 睡眠检查清单

- [ ] 卧室足够黑暗
- [ ] 温度适宜（18-22°C）
- [ ] 固定作息时间
- [ ] 睡前1小时不看手机
- [ ] 下午2点后不摄入咖啡因

## 三、运动规划

### 3.1 运动建议

| 年龄段 | 每周运动 | 运动类型 | 注意事项 |
|--------|----------|----------|----------|
| 18-30 | 150分钟 | 有氧+力量 | 循序渐进 |
| 30-50 | 150分钟 | 有氧+柔韧 | 注意关节 |
| 50-65 | 120分钟 | 太极/快走 | 避免剧烈 |

|------|----------|--------|----------|

### 6.2 常见急救处理

| 情况 | 处理方式 |
|------|----------|
| 烫伤 | 冷水冲洗15分钟 |
| 割伤 | 加压止血+消毒 |
| 骨折 | 固定+不要移动 |
| 中暑 | 阴凉处+补水 |
| 过敏 | 抗过敏药+就医 |
