# 积分学

> **核心观点**：积分是微分的逆运算，是计算面积、体积和累积量的工具。

---

## 📊 积分基本概念

### 不定积分

| 概念 | 定义 | 意义 |
|------|------|------|
| 不定积分 | ∫f(x)dx = F(x) + C | 原函数族 |
| 被积函数 | f(x) | 要积分的函数 |
| 积分变量 | dx | 积分变量 |
| 积分常数 | C | 任意常数 |

## 📈 微积分基本定理

### 牛顿-莱布尼茨公式

| 定理 | 公式 | 意义 |
|------|------|------|
| 牛顿-莱布尼茨 | ∫ₐᵇf(x)dx = F(b) - F(a) | 微分与积分互逆 |
| 变上限积分 | d/dx∫ₐˣf(t)dt = f(x) | 原函数存在 |

### 定积分性质

```
定积分性质：
1. 线性性：∫(af+bg) = a∫f + b∫g
2. 区间可加：∫ₐᵇ = ∫ₐᶜ + ∫ᶜᵇ
3. 保号性：f≥0 → ∫f ≥ 0
4. 中值定理：∫ₐᵇf = f(ξ)(b-a)
```

## 🎯 核心结论

### 积分学核心概念

1. **不定积分**：原函数族
2. **定积分**：面积/累积量
3. **微积分基本定理**：微分与积分互逆
4. **积分方法**：换元、分部、部分分式
5. **应用**：几何、物理、概率
