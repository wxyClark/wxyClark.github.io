# AI-IT 知识体系

> **第一性原理**：AI-IT是从信息处理出发，构建智能系统和信息技术解决方案的学科群。

---

## 📚 AI-IT的公理体系

### 第一性原理：信息可处理性

```
AI-IT的基本信念：
1. 信息可以被编码和传输
2. 计算可以模拟智能
3. 数据是智能的基础
4. 系统由部件组成
```
