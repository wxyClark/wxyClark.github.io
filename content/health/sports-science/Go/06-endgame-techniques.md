# 围棋官子技巧 — 精进球后阶段

## 一、什么是官子？

官子是围棋第三阶段（布局→中盘→官子），指双方地盘基本确定后的收尾阶段。

**重要性**：
- 胜负常在1-2目之间决定
- 官子失误可导致局势逆转
- 高手之间的差距常在官子

---

## 二、官子分类

### 2.1 按价值分类
| 类型 | 目数 | 优先级 |
|------|------|--------|
| 大官子 | 10目以上 | 最高 |
| 中官子 | 5-10目 | 高 |
| 小官子 | 1-5目 | 中 |
| 单官 | 0目 | 最后 |

### 2.2 按性质分类
| 类型 | 特点 | 价值计算 |
|------|------|----------|
| 先手官子 | 对方必须应 | 双倍价值 |
| 后手官子 | 对方可不理 | 正常价值 |
| 逆收官子 | 对方先手变后手 | 双倍价值 |

---

## 三、官子计算方法

### 3.1 基本公式
```
官子价值 = 黑走得目 + 白走得目
```

### 3.2 具体例子
**例子1**：黑走得2目，白走得1目
- 价值 = 2 + 1 = 3目（后手3目）

**例子2**：黑先手得2目，白先手得1目
- 价值 = (2+1) × 2 = 6目（逆收6目）

### 3.3 逆收判断
```
如果对方不走，我能得X目
如果对方走了，我只能得Y目
逆收价值 = (X - Y) × 2
```

## 四、官子优先级

### 4.1 口诀
```
先手官子要抢完，
逆收大官子优先，
后手官子按大小，
单官最后再填满。
```

### 4.2 顺序表
| 顺序 | 类型 | 处理方式 |
|------|------|----------|
| 1 | 所有先手官子 | 全部走到 |
| 2 | 大逆收官子 | 优先逆收 |
| 3 | 后手大官子 | 按大小顺序 |
| 4 | 后手中官子 | 继续按大小 |
| 5 | 后手小官子 | 最后处理 |
| 6 | 单官 | 全部走满 |

## 五、常见官子手筋

### 5.1 一路妙手
```
在一路（底线）常有妙手：
  ● ● ● ●
  ● · · ●
  ● ● ● ●
```
→ 一路扳、一路跳是好手

### 5.2 二路透点
```
二路透点常是巧手：
  ● ● ●
  · ○ ·
  ● ● ●
```
→ 点入二路可破眼或得地

### 5.3 跳入飞出
```
轻灵的进入方式：
  ● · · ●
  · ○ ·   ← 跳入或飞出
  ● · · ●
```

## 六、官子实战技巧

### 6.1 形势判断
- 数清双方实地
- 判断优劣势
- 制定对应策略

### 6.2 时间管理
- 大官子多花时间
- 小官子快速处理
- 避免时间恐慌

### 6.3 避免错误
| 错误 | 后果 | 改正 |
|------|------|------|
| 在己方地内走棋 | 浪费手效 | 找对方缺陷 |
| 忽略逆收官子 | 失去利益 | 优先逆收 |
| 计算失误 | 局势逆转 | 仔细计算 |
