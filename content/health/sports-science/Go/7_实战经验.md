# 围棋实战经验 — 从入门到进阶

## 一、开局经验

### 1.1 开局三原则
```
1. 占角优先 — 四个角先占
2. 快速展开 — 尽快占满大场
3. 均衡发展 — 四面兼顾不偏废
```

### 1.2 常见开局错误
| 错误 | 表现 | 改正 |
|------|------|------|
| 重复走同一区域 | 同角落多次 | 四面开花 |
| 过早战斗 | 没展开就打架 | 先占大场 |
| 忽视对方厚势 | 走进厚势范围 | 避开厚势 |

### 1.3 开局检查清单
- [ ] 四个角是否都占了？
- [ ] 是否有弱棋需要处理？
- [ ] 对方厚势在哪里？
- [ ] 接下来最大的地方在哪？

---

## 二、中盘经验

### 2.1 攻击时的判断
```
问自己：
1. 这手棋能获利吗？
2. 对方能反击吗？
3. 我自身有缺陷吗？
```

### 2.2 防守时的判断
```
问自己：
1. 这棋能活吗？
2. 需要补几手？
3. 能否弃子转身？
```

### 2.3 中盘错误
| 错误 | 后果 | 改正 |
|------|------|------|
| 盲目攻击 | 自身变薄 | 攻彼顾我 |
| 消极防守 | 失去机会 | 攻防平衡 |
| 忽视大局 | 局部赢全局输 | 全局思维 |

---

## 三、官子经验

### 3.1 官子原则
```
✓ 先大后小
✓ 先逆后顺
✓ 先手保留
✗ 不要在己方实地内走棋
✗ 不要忽略逆收
```

### 3.2 官子错误
| 错误 | 后果 | 改正 |
|------|------|------|
| 漏掉大官子 | 损失目数 | 全局扫描 |
| 计算失误 | 局势逆转 | 仔细计算 |
| 时间不够 | 草率收兵 | 合理分配 |

## 四、心态管理

### 4.1 优势心态
```
✓ 保持冷静，不松懈
✓ 稳健行棋，不冒险
✓ 注意对方反扑
✗ 不要得意忘形
✗ 不要提前庆祝
```

### 4.2 劣势心态
```
✓ 不放弃，寻找机会
✓ 制造混乱，复杂化
✓ 抓住对方失误
✗ 不要自暴自弃
✗ 不要随便认输
```

### 4.3 均势心态
```
✓ 认真对待每一手
✓ 不犹豫，果断落子
✓ 保持专注
✗ 不要急躁
✗ 不要犹豫不决
```

## 五、复盘方法

### 5.1 复盘步骤
```
1. 确认胜负
2. 找出关键手
3. 分析得失原因
4. 总结经验教训
5. 记录改进计划
```

### 5.2 复盘重点
| 阶段 | 重点 |
|------|------|
| 布局 | 是否遵循三原则 |
| 中盘 | 攻击防守是否得当 |
| 官子 | 是否有漏掉的大官子 |

### 5.3 复盘习惯
- 每局棋必复盘
- 重要比赛详细复盘
- 平时对局快速复盘

---

## 六、实战建议

### 6.1 对弈前
- 充足休息
- 调整心态
- 熟悉用时规则

### 6.2 对弈中
- 控制时间
- 保持专注
- 不受外界干扰

### 6.3 对弈后
- 无论胜负都复盘
- 学习对手优点
- 改进自身不足
