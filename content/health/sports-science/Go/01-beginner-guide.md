# 围棋第一步 — 新手入门指南

## 一、什么是围棋？

围棋是一种两人对弈的strategy棋类游戏，用黑白棋子在19×19的棋盘上争夺地盘。谁围的地多，谁就赢。

**核心目标**：在棋盘上围出更多的地（交叉点）。

## 三、基本规则（必须掌握的4条）

### 规则1：气——棋子的生命线
每个棋子周围有**几条横线/竖线空着**，就有**几口气**。

```
  ●     →  只有1口气（危险！）
  ·
  ● ● ●   →  有3口气

  ● ●     →  有4口气（安全）
  · ·
```

**实战要点**：
- 气越多越安全
- 气越少越危险
- 气全部被堵住 → 棋子被提走

### 规则2：落子
- 黑棋先下，黑白交替
- 落子后**不能移动**
- 可以下在任何**空交叉点**

### 规则3：提子
当一组棋子的**所有气都被堵住**时，这组棋子被提走。

```
举例：
  ○ ○ ○
  ○ ● ○   ← 黑子被围，无气
  ○ ○ ○
```
→ 黑子被提走

### 规则4：胜负
- 棋下完后，数双方围的交叉点数量
- 中国规则：**黑棋贴3又3/4子**（约7.5目）
- 地多者胜

## 四、第一局棋怎么下？（实战步骤）

### Step 1：占角（第1-4手）
**口诀**：四个角先占

```
常见占角方式：
  ●       ●         ●
   ·  或   ·  或    ·
  ● ●     ● ●      · ●
```
- **星位**：第4线第4列（(4,4)等）
- **小目**：第3线第4列
- **三三**：第3线第3列

### Step 2：守角（第5-8手）
```
小飞守角：       大飞守角：
  · · ·           · · ·
  · ● ·           · · ·
  ● ○ ●     或    ● · ●
  · ● ·           · ○ ·
  · · ·           · · ·
```

### Step 3：拆边（第9-12手）
从角向边展开，形成"角+边"的根据地。

```
拆二（安全）：    拆三（需防夹击）：
  ● · · ●         ● · · · ●
```

### Step 4：进入中盘
角和边基本占完后，开始争夺中央和攻击弱棋。

## 五、新手必会的3个技巧

### 技巧1：打吃
让对方棋子只剩1口气。

```
  ○ ○
  ○ ●   ← 白棋被打吃（只剩1口气）
  ○ ○
```
对方必须应，否则被提。

### 技巧2：连接
把分散的棋子连成一体，增加气数。

```
  ●   ●      ● ●      →  更安全
  ·   ·  →   · ·
  ●   ●      ● ●
```

### 技巧3：做眼
围出一个空交叉点，就是"眼"。有两个眼就活棋。

```
  ● ● ●
  ● · ●   ← 这个·就是一个眼
  ● ● ●
```
