# 围棋中盘战斗 — 攻击与防守

## 一、中盘的基本任务

```
布局完成后 → 中盘战斗 → 官子收束
     ↓           ↓           ↓
  占角开    攻击防守     精细收官
  展边场    形势判断     顺序优化
```

**中盘三大任务**：
1. 攻击对方弱棋
2. 防守己方弱棋
3. 抢占大场和急所

---

## 二、攻击技巧（4种方法）

### 2.1 逼攻
迫使对方向己方厚势逃跑。

```
正确做法：
  ● ● ●
  ● ○ ●   ← 白弱棋
  ● · ●
     ↑
  逼向黑厚势方向
```

### 2.2 缠绕攻击
同时攻击两块弱棋，让对手顾此失彼。

```
策略：
- A块弱棋 → 从左边攻击
- B块弱棋 → 从右边攻击
- 让对手两头不能兼顾
```

### 2.3 搜根攻击
攻击对方根据，不让其做活。

```
要点：
- 破坏对方眼位
- 不让对方轻松做活
- 借攻击获取利益
```

### 2.4 攻击原则
```
✓ 攻彼顾我 — 攻击时注意自身安全
✓ 借攻成势 — 通过攻击获取外势或实地
✗ 盲目追击 — 不计代价追逃
✗ 不顾自身 — 只顾进攻忽略防守
```

## 三、防守技巧（4种方法）

### 3.1 出头
向中央逃跑，摆脱包围。

```
被包围时：
  ● ● ●
  ● ○ ●
  ● ● ●
      ↓
  向中央跳/飞出头
```

### 3.2 做眼
就地做活，争取两眼。

```
做眼要点：
- 优先占据眼位要点
- 避免假眼
- 保留弹性
```

### 3.3 腾挪
利用对方缺陷，就地处理。

```
腾挪思路：
1. 寻找对方棋形缺陷
2. 利用对方的弱点
3. 舍弃部分换取整体安全
```

### 3.4 弃子
该舍则舍，舍小就大。

```
弃子时机：
- 弱棋难以两全
- 舍弃能获取更大利益
- 转换后局面有利
```

## 四、实战决策树

```
发现对方弱棋？
├── 能攻击获利？ → 发起攻击
│                 ├── 获取实地 → 逼向实地
│                 └── 获取外势 → 逼向中央
├── 攻击有风险？ → 先补强自身
└── 无法攻击？ → 抢占其他大场

发现己方弱棋？
├── 能做活？ → 尽快做活
├── 能出头？ → 向中央逃跑
├── 能腾挪？ → 寻找对方缺陷
└── 都要不掉？ → 果断弃子
```

## 五、常见战斗错误

| 错误 | 表现 | 后果 | 改正 |
|------|------|------|------|
| 盲目攻击 | 不管利弊就冲 | 自身变薄 | 先评估得失 |
| 过分保守 | 不敢战斗 | 丧失机会 | 抓住战机 |
| 只顾自己 | 不顾全局 | 失去配合 | 全局思维 |
| 忽视对手 | 不计算反击 | 被反杀 | 计算变化 |

## 七、实战检查清单

对局时随时问自己：
- [ ] 对方有弱棋吗？能攻击吗？
- [ ] 我有弱棋吗？需要处理吗？
- [ ] 现在最大的地方在哪里？
- [ ] 这手棋是攻击还是防守？
