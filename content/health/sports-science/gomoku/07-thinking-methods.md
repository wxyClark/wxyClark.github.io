# 五子棋思维方式 — 从计算到大局

## 一、计算思维

### 1.1 计算深度
| 级别 | 计算步数 | 训练方法 |
|------|----------|----------|
| 入门 | 3-5步 | 基础攻防题 |
| 进阶 | 10-15步 | VCF/VCT练习 |
| 高级 | 20+步 | 实战对局 |

### 1.2 计算顺序
```
第1层：对方最强应手
第2层：我的最佳应对
第3层：对方第二选择
第4层：我的第二选择
...
直到确定结果
```

### 1.3 计算训练
- 每天做VCF/VCT题（至少5道）
- 拆解棋谱变化
- 模拟实战计算

## 二、形势判断思维

### 2.1 快速判断
```
关键问题：
1. 谁有先手？
2. 谁的棋形更好？
3. 哪里是急所？
4. 谁更接近胜利？
```

### 2.2 判断流程
```
1. 检查双方活三/冲四
2. 评估棋形好坏
3. 计算关键变化
4. 判断优劣程度
5. 制定对应策略
```

### 2.3 判断练习
每10手棋做一次形势判断：
- 现在是优还是劣？
- 差距有多大？
- 接下来该怎么做？

---

## 三、全局思维

### 3.1 局部与全局
```
局部好 ≠ 全局好
全局好 > 局部好

例子：
- 局部禁手虽胜但失去全局 → 不可取
- 局部亏损但获取先手 → 可接受
```

### 3.2 大局观培养
| 方法 | 说明 |
|------|------|
| 多看名局 | 学习高手全局观 |
| 多复盘 | 分析全局得失 |
| 多思考 | 每手棋问为什么 |

---

## 四、攻防思维

### 4.1 进攻思维
```
进攻三问：
1. 这手棋能形成威胁吗？
2. 对方能防守吗？
3. 后续能连接吗？
```

### 4.2 防守思维
```
防守三问：
1. 这手棋能防守住吗？
2. 有没有更好的防守？
3. 防守后能反击吗？
```

### 4.3 转换思维
```
何时转换：
- 进攻受阻 → 转为防守
- 防守成功 → 寻找反击
- 发现新机会 → 及时调整
```

---

## 五、禁手思维

### 5.1 黑棋思维
```
进攻时：
- 优先考虑四三胜
- 避免形成双三/双四
- 控制连子不超过5

防守时：
- 注意对方禁手陷阱
- 避免落入对方圈套
```

### 5.2 白棋思维
```
进攻时：
- 寻找禁手点设置陷阱
- 逼迫黑棋走向禁手
- 保留禁手反击手段
```

## 六、思维训练方法

### 6.1 每日思考
每手下棋前问：
- 这手棋的理由是什么？
- 有没有更好的选择？
- 对方会怎么应？
- 是否符合禁手规则？

### 6.2 复盘思考
- 哪手棋可以更好？
- 为什么当时那么下？
- 下次遇到类似情况怎么做？

### 6.3 名局思考
- 高手为什么这么下？
- 如果不这么下会怎样？
- 我能学到什么？

---

## 七、思维误区

| 误区 | 表现 | 改正 |
|------|------|------|
| 只看局部 | 不顾全局 | 培养大局观 |
| 只算一条 | 遗漏变化 | 多算几条 |
| 只顾进攻 | 忽视防守 | 攻防平衡 |
| 忽视禁手 | 意外判负 | 牢记禁手 |
