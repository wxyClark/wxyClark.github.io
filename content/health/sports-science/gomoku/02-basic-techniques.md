# 五子棋基础技巧 — 攻防基础

## 一、基本棋形

### 1.1 三的分类
| 类型 | 形状 | 特点 | 威胁度 |
|------|------|------|--------|
| 活三 | ○ ○ ○ | 两端都空 | ⭐⭐⭐ |
| 冲四 | ● ○ ○ ○ | 一端被封 | ⭐⭐⭐⭐ |
| 眠三 | ● ○ ○ ○ ● | 两端都被封 | ⭐ |

### 1.2 四的分类
| 类型 | 形状 | 特点 | 威胁度 |
|------|------|------|--------|
| 活四 | ○ ○ ○ ○ | 两端都空 | ⭐⭐⭐⭐⭐（必胜）|
| 冲四 | ● ○ ○ ○ ○ | 一端被封 | ⭐⭐⭐⭐ |
| 眠四 | ● ○ ○ ○ ○ ● | 两端都被封 | ⭐⭐ |

## 二、进攻技巧

### 2.1 四三胜（核心技巧）
**定义**：同时形成一个冲四和一个活三

```
进攻示例：
  ● ● ● ●
      ○ ○ ○
```
→ 下一个子同时形成四和三，对手无法同时防守

### 2.2 双活三
**注意**：黑棋双活三是**禁手**！

```
错误示范（黑棋禁手）：
  ○ ○ ○
  ● ● ●
```
→ 同时形成两个活三，黑棋输

### 2.3 连续进攻
**VCF（Victory by Continuous Fours）**：连续冲四获胜
```
步骤：
1. 第一冲四 → 对手必须应
2. 第二冲四 → 对手必须应
3. 第三冲四 → 形成四三胜
```

**VCT（Victory by Continuous Threats）**：连续做杀获胜
```
步骤：
1. 做活三 → 对手必须防守
2. 再做活三 → 形成四三胜
```

## 三、防守技巧

### 3.1 活三的防守
```
对方活三时，你有两个选择：
1. 堵在一端（通常选有己方棋子的一端）
2. 形成反冲四（进攻优于防守）
```

### 3.2 冲四的防守
```
对方冲四时，必须防守！
- 唯一的防守点就是延伸成五的位置
- 如果不防，对方直接连五获胜
```

### 3.3 防守原则
| 情况 | 原则 | 原因 |
|------|------|------|
| 对方活三 | 优先防守 | 不防会输 |
| 对方冲四 | 必须防守 | 不防直接输 |
| 对方眠三 | 可选择 | 威胁较小 |

## 四、基本定式

### 4.1 云月开局基本型
```
黑1: (8,8) 天元
白2: (8,9) 上
黑3: (7,8) 左
白4: (7,9) 左上
```
这是最基础的开局，后续变化很多。

### 4.2 浦月开局特点
```
特点：黑棋进攻性强
关键：形成多个活三
注意：避免双三禁手
```

## 五、常见错误

| 错误 | 表现 | 后果 | 改正 |
|------|------|------|------|
| 忽视禁手 | 形成双三/双四 | 直接判负 | 记住禁手规则 |
| 盲目进攻 | 不顾防守 | 被对方反杀 | 攻防平衡 |
| 只看眼前 | 不计算后续 | 失去优势 | 多算几步 |
| 轻视防守 | 只攻不防 | 被逆转 | 重视防守 |
