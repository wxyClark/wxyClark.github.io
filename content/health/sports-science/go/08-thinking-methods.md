# 围棋思维方式 — 从计算到大局

## 一、计算思维

### 1.1 计算深度
| 级别 | 计算步数 | 训练方法 |
|------|----------|----------|
| 入门 | 3-5步 | 基础死活题 |
| 进阶 | 10-15步 | 中等难度题目 |
| 高级 | 20+步 | 复杂实战变化 |

### 1.2 计算顺序
```
第1层：对方最强应手
第2层：我的最佳应对
第3层：对方第二选择
第4层：我的第二选择
...
直到确定结果
```

### 1.3 计算训练
- 每天做死活题（至少5道）
- 拆解棋谱变化
- 模拟实战计算

## 二、形势判断思维

### 2.1 快速判断法
```
黑空 = 黑实地 + 黑外势
白空 = 白实地 + 白外势

判断：
- 黑空 > 白空 → 黑优
- 黑空 < 白空 → 白优
- 黑空 ≈ 白空 → 均势
```

### 2.2 判断流程
```
1. 数实地 — 已确定的地
2. 估外势 — 潜在影响力
3. 看厚薄 — 安全程度
4. 判先后 — 谁有先手
5. 定策略 — 优/劣/均
```

### 2.3 判断练习
每10手棋做一次形势判断：
- 现在是优还是劣？
- 差距有多少目？
- 接下来该怎么做？

## 三、全局思维

### 3.1 局部与全局
```
局部好 ≠ 全局好
全局好 > 局部好

例子：
- 局部亏损但获取先手 → 可接受
- 局部获利但失去全局 → 不可取
```

### 3.2 大局观培养
| 方法 | 说明 |
|------|------|
| 多看名局 | 学习高手大局观 |
| 多复盘 | 分析全局得失 |
| 多思考 | 每手棋问为什么 |

---

## 四、取舍思维

### 4.1 舍小就大
```
原则：
- 小利让位于大义
- 局部让位于全局
- 当下让位于未来
```

### 4.2 弃子思维
```
何时弃子？
✓ 弃子能获取更大利益
✓ 弃子能转换局势
✓ 弃子能争取先手

如何弃子？
- 计算弃子后的收益
- 确保转换有利
- 不要无意义弃子
```

---

## 五、辩证思维

### 5.1 攻与守
```
攻中有守：攻击时注意自身缺陷
守中有攻：防守时寻找反击机会
```

### 5.2 地与势
```
实地多时 → 取外势
外势强时 → 取实地
根据全局灵活转换
```

### 5.3 厚与薄
```
厚棋 → 可攻击，可围地
薄棋 → 需补强，需安定
```

---

## 六、思维训练方法

### 6.1 每日思考
每手下棋前问：
- 这手棋的理由是什么？
- 有没有更好的选择？
- 对方会怎么应？

### 6.2 复盘思考
- 哪手棋可以更好？
- 为什么当时那么下？
- 下次遇到类似情况怎么做？

### 6.3 名局思考
- 高手为什么这么下？
- 如果不这么下会怎样？
- 我能学到什么？

---

## 七、思维误区

| 误区 | 表现 | 改正 |
|------|------|------|
| 只看局部 | 不顾全局 | 培养大局观 |
| 只算一条 | 遗漏变化 | 多算几条 |
| 只顾进攻 | 忽视防守 | 攻防平衡 |
| 贪小失大 | 计较局部 | 舍小就大 |
