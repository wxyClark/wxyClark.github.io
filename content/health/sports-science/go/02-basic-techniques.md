# 围棋基础技巧 — 吃子与连接

## 一、吃子技巧（5种基本方法）

### 1.1 直接打吃
让对方棋子只剩一口气，下次就能提。

```
练习1：黑先吃白
  · · · · ·
  · ○ ○ · ·
  · ○ ● ○ ·   ← 黑棋打吃白棋
  · · · · ·
```
→ 白棋只剩1口气，黑下在○位置即可提子

### 1.2 征子（扭羊头）
连续打吃，逼迫对方沿斜线逃跑，最终围住。

```
征子路线示意：
     ●
    · ●
   ○ · ●
  · ○ · ●
 ● · ○ · ●
```
**要点**：
- 永远从侧面打吃（不是正面）
- 迫使对方往己方厚势方向跑
- 计算清楚征子路线再实施

### 1.3 枷吃（门吃）
不直接打吃，而是用包围圈困住对方。

```
被枷的白棋：
  ● ● ●
  ● ○ ●   ← 白棋被罩住，无法逃脱
  ● ● ●
```
**优点**：比征子更简洁，不依赖周边配合

### 1.4 扑
主动送一子，诱使对方提，再反提更多子。

```
扑的妙手：
  · ● ·
  ● ○ ●   ← 黑扑入！
  · ● ·
```
→ 白提黑后，黑再反提白棋

### 1.5 倒扑
送两子或更多，让对方提后自撞一气，再反提。

```
倒扑形状：
  ● ● ●
  ● ○ ○ ●
  · · ○ ·
```
→ 黑先送一子，白提后形成倒扑

## 二、连接技巧（4种基本方法）

### 2.1 长
向前延伸，增加气数。

```
●      ●
 ·  →   ●
  ●     ·
```

### 2.2 跳
小跳（日字对角），轻灵连接。

```
●      ●
 ·  →   ·
  ·     ●
```

### 2.3 飞
大飞（目字对角），快速展开。

```
●         ●
 ·    →    ·
  ·        ·
   ●
```

### 2.4 虎
形成虎口，坚固连接。

```
● ●      ● ●
 ·  →     · ●
  ●       ● ·
```

## 三、逃子技巧

### 3.1 出头
向中央逃跑，摆脱包围。

```
被包围时：
  ● ● ●
  ● ○ ●   ← 白被围
  ● ● ●
```
→ 向中央跳/飞出头

### 3.2 腾挪
利用对方缺陷，就地做活或逃出。

```
原则：
- 不要盲目逃跑
- 寻找对方棋形缺陷
- 借劲使力
```

## 四、每日练习（15分钟）

### 练习1：数气（5分钟）
随机摆几个棋子，快速数出气数。

```
  ● ○ ●
  · ○ ·
  ● ○ ●
```
→ 中间白棋有几口气？（答案：4口）

### 练习2：吃子题（5分钟）
找5道简单吃子题，限时完成。

### 练习3：连接题（5分钟）
找5道连接题，思考最佳连接方式。

## 五、常见错误

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 盲目逃跑 | 越跑越危险 | 先判断能否做活 |
| 忽视打吃 | 被提子 | 时刻关注对方打吃 |
| 重复连接 | 效率低 | 选择高效连接方式 |
| 强行突围 | 损失更大 | 适时弃子转身 |
