# 五子棋中盘战术 — 复杂战斗技巧

## 一、中盘概述

中盘是五子棋最复杂的阶段，需要：
- 精确的计算能力
- 战术组合运用
- 攻防转换判断

---

## 二、进攻战术

### 2.1 VCF（连续冲四胜）
**定义**：通过连续冲四最终获胜

```
VCF示例：
第1手：冲四 → 对手必须应
第2手：冲四 → 对手必须应
第3手：冲四 → 形成四三胜
```

**要点**：
- 每一步都要计算清楚
- 确保最终能形成胜势
- 注意对手的防守可能性

### 2.2 VCT（连续做杀胜）
**定义**：通过连续做杀最终获胜

```
VCT示例：
第1手：做活三 → 对手必须防
第2手：再做活三 → 形成四三胜
```

**要点**：
- 做杀要考虑对手防守
- 确保后续能连接上
- 注意禁手问题

### 2.3 三三陷阱
**定义**：诱导对手形成双三禁手

```
陷阱设置：
黑棋故意留下双三机会
白棋以为能赢，形成双三
结果：黑棋获胜（白棋禁手）
```

### 2.4 四四陷阱
**定义**：诱导对手形成双四禁手

```
与三三陷阱类似
关键是诱使对方形成四四
```

## 三、防守战术

### 3.1 活三防守
```
对方活三时：
选择1：堵在己方有子的一端
选择2：形成反冲四（进攻防守）
选择3：形成反活三（如果可能）
```

### 3.2 冲四防守
```
对方冲四时：
唯一选择：挡在延伸点
必须防守：否则会直接输
```

### 3.3 预防性防守
```
在对方形成活三之前：
- 预先阻挡可能的延伸
- 破坏对方的棋形配合
- 抢占关键点
```

## 四、战术组合

### 4.1 一子双杀
**定义**：一手棋同时形成两个威胁

```
示例：
     ○
    ○ ○ ○
     ○
```
→ 一手棋同时形成两个活三

### 4.2 间接活三
**定义**：不是直接形成活三，而是通过后续手段形成

```
间接活三示例：
先下A点，迫使对方防守
再下B点，形成真正的活三
```

### 4.3 跳活三
**定义**：中间有空格的活三

```
跳活三：○ · ○ ○
        或 ○ ○ · ○
```
**特点**：比连活三更难防守

## 五、攻防转换

### 5.1 由攻转守
```
何时转换：
- 进攻被对方化解
- 自身出现弱点
- 对方反击威胁更大
```

### 5.2 由守转攻
```
何时转换：
- 成功防守住对方进攻
- 发现对方棋形缺陷
- 形成反杀机会
```

### 5.3 转换判断要点
| 情况 | 选择 |
|------|------|
| 进攻有效 | 继续进攻 |
| 进攻受阻 | 转为防守 |
| 防守成功 | 寻找反击 |
| 防守失败 | 准备认输 |

## 六、实战计算

### 6.1 计算深度
| 级别 | 计算步数 | 训练方法 |
|------|----------|----------|
| 入门 | 3-5步 | 基础死活题 |
| 进阶 | 10-15步 | VCF/VCT练习 |
| 高级 | 20+步 | 实战对局 |

### 6.2 计算顺序
```
1. 计算对方最强应手
2. 计算我的最佳应对
3. 反复推演至确定结果
4. 验证是否有遗漏变化
```

---

## 七、常见错误

| 错误 | 后果 | 改正 |
|------|------|------|
| 只算一步 | 被对方反击 | 多算几步 |
| 忽视禁手 | 意外判负 | 牢记禁手规则 |
| 盲目进攻 | 被反杀 | 攻防平衡 |
| 忽略防守 | 被逆转 | 重视防守 |
