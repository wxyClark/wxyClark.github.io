# 五子棋禁手规则 — 黑棋的限制与反制

## 一、禁手的基本概念

### 1.1 为什么要设禁手？
- 五子棋黑棋先行有巨大优势
- 禁手是为了平衡黑白双方的胜率
- 没有禁手的五子棋，黑棋必胜

### 1.2 禁手只适用于黑棋
```
黑棋：有禁手限制
白棋：无禁手，自由落子
```

---

## 二、三大禁手详解

### 2.1 三三禁手
**定义**：一手棋同时形成两个或以上的活三

```
禁手示例：
  ○ ○ ○
  ● ● ●
      ↑
  这手棋同时形成两个活三 → 禁手，黑输
```

**注意**：
- 必须是**活三**，冲三不算
- 可以是任何方向（横、竖、斜）
- 只要同时形成两个就判负

### 2.2 四四禁手
**定义**：一手棋同时形成两个或以上的四

```
禁手示例：
  ● ● ● ●
      ○ ○ ○ ○
      ↑
  这手棋同时形成两个四 → 禁手，黑输
```

**注意**：
- 包括活四和冲四
- 两个冲四也是禁手
- 一个活四加一个冲四也是禁手

### 2.3 长连禁手
**定义**：一手棋形成六子或以上连珠

```
禁手示例：
  ● ● ● ● ● ●
              ↑
  六子长连 → 禁手，黑输
```

**注意**：
- 五子不算长连
- 六子及以上才算
- 即使是同时形成五子，只要超过五子也是禁手

## 三、禁手的判断要点

### 3.1 活三 vs 冲三
```
活三（禁手计算）：
  ○ ○ ○    → 两端都空，可延伸
  ○ ○ ○ ●  → 一端被封，是冲三

判断方法：看两端是否都有空位
```

### 3.2 四的类型
```
活四（禁手计算）：
  ○ ○ ○ ○  → 两端都空

冲四（禁手计算）：
  ● ○ ○ ○ ○ → 一端被封
  
  ○ ○ ○ ○ ● → 一端被封

判断方法：看是否只有一端能延伸
```

### 3.3 特殊情况
```
1. 一子双杀：如果同时形成四三，四三优先，不算禁手
2. 长连同时五子：如果同时形成五子长连，五子胜，不算禁手
3. 禁手点对方可避：如果对方可以避免禁手，则不算禁手
```

## 四、禁手的应用

### 4.1 黑棋如何规避禁手
| 情况 | 方法 |
|------|------|
| 想形成双三 | 改为形成四三（四三优先）|
| 想形成双四 | 改为形成四三 |
| 可能形成长连 | 控制连子数量不超过5 |

### 4.2 白棋如何利用禁手
| 策略 | 方法 |
|------|------|
| 诱使黑棋禁手 | 留出双三/双四机会 |
| 逼迫黑棋长连 | 封堵一侧逼黑超五 |
| 制造禁手陷阱 | 设置看似能赢实则禁手的位置 |

### 4.3 经典禁手战术
```
三三陷阱：
白棋故意留下空档
黑棋以为能双三胜
结果：黑棋形成双三禁手，白胜

四四陷阱：
白棋诱导黑棋形成双四
黑棋落子后判负
```

## 五、禁手实战技巧

### 5.1 识别禁手点
```
看到棋盘时问：
1. 这个点会不会形成双三？
2. 这个点会不会形成双四？
3. 这个点会不会形成长连？
```

### 5.2 计算禁手
```
落子前计算：
1. 这手棋会形成几个活三？
2. 这手棋会形成几个四？
3. 这手棋会形成几子连珠？
```

### 5.3 利用禁手
```
白棋策略：
- 制造双三机会给黑棋
- 逼迫黑棋走向禁手点
- 保留禁手反击手段
```

## 六、常见误区

| 误区 | 正确理解 |
|------|----------|
| 所有双三都是禁手 | 只有同时形成两个活三才是 |
| 冲三也算禁手 | 只有活三才计算 |
| 长连五子也是禁手 | 五子刚好是胜，只有六子以上才是 |
| 禁手只在进攻时 | 防守时也要注意禁手 |

### 每日练习（15分钟）
1. **禁手识别**（5分钟）
   - 看各种棋形，判断是否禁手
2. **禁手计算**（5分钟）
   - 计算某手棋是否会形成禁手
3. **禁手实战**（5分钟）
   - 对局中刻意使用禁手战术
