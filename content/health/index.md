# 健康知识体系

> **第一性原理**：健康科学从生命活动的规律出发，维护人类健康和预防疾病。

---

## 📚 健康科学的公理体系

### 第一性原理：生命可维护性

```
健康科学的基本信念：
1. 生命活动遵循生物学规律
2. 疾病可以预防和治疗
3. 健康需要主动维护
4. 身心是社会统一体
```
