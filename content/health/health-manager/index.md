## 三、全局核心知识点（一套书只记这些）

| 领域 | 必背 |
|------|------|
| 角色边界 | 能做：评估/建议/随访/健康教育；不能做：诊断/处方/治疗决策 |
| 血压 | 诊断 ≥140/90mmHg（成人诊室，非同日 3 次）；1级 140-159/90-99；目标 <140/90（耐受 <130/80） |
| 血糖 | 诊断空腹 ≥7.0 / HbA1c ≥6.5%；目标空腹 4.4-7.0mmol/L；低血糖 <3.9 清醒吃 15g 糖 |
| 血脂 | LDL-C 高危目标 <2.6mmol/L（极高危 <1.8） |
| BMI | 成人正常 18.5-23.9；≥28 肥胖；腰围 男≥90 女≥85 |
| 三大产能 | 碳水 50-60%、蛋白 15-20%、脂肪 20-30% |
| 运动 | 成人 150-300min/周中等强度 + 2 次抗阻；靶心率 (220-年龄)×60-80% |
| 心理量表 | PHQ-9 / GAD-7：≥5 轻 / ≥10 中 / ≥15 中重；量表筛不诊 |
| 5A 戒烟 | Ask/Advise/Assess/Assist/Arrange |
| 传染病 | 三环节 = 传染源/传播途径/易感人群；甲类 = 鼠疫/霍乱 |
| 数据合规 | 健康信息属敏感个人信息，须单独同意 |
