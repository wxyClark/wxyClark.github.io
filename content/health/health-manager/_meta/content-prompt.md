# 提示词：生成「健康管理师」知识库（考试 + 行业实操）

## 1. 任务目标

在 `content/health/health-manager/` 目录下，创建一套**自顶向下**的健康管理知识文档，覆盖：

1. **三级/高级工 健康管理师 考试知识点**（9 大模块，对应考纲）
2. **大健康行业实操扩展**（2 个模块：行业实操、边界与法规）

要求：重点突出、条理清晰、方便记忆；合理使用 mermaid 图形化表达；每个模块末尾配「一页速查表」。

## 2. 目标读者与定位

- 读者：非医学背景的从业者/考证者，目标是**考过三级 + 直接上手**营养建议、生活习惯指导、陪诊服务
- 定位：「核心 20% 知识解决 80% 场景」——每个模块先抓高频考点与高频业务点，再展开细节
- 语言：简体中文；术语保留英文缩写（BMI、HbA1c、CPR 等）

## 3. 金字塔结构（自顶向下）

```
L0  定位层   index.md          —— 是什么、为谁服务、13 个模块全景图、学习优先级
L1  框架层   00-overview.md    —— 9+2 模块关系 mermaid 全景图 + 考试题型权重 + 30/60/90 天学习路线
L2  模块层   01 ~ 11           —— 每个模块自顶向下：核心考点 → 关键概念 → 易混淆点/常见坑
L3  速查层   每个模块末尾      —— 「一页速查」表格（问题 → 答案），沿用项目既有风格
```

## 5. 单模块内部结构规范（L2 → L3）

每个 `0X-*.md` 模块按以下顺序组织：

1. **模块定位**（2~3 行）：一句话说明「这个模块解决什么问题」+ 在考试中的权重/优先级标注（★~★★★）
2. **核心考点/核心流程**：优先用 **mermaid flowchart** 表达流程型知识（如健康管理流程、5A 流程、FITT 五要素）；用**表格**表达对比型/数值型知识（如血压目标值、营养素比例、分界值）
3. **关键概念展开**：`### 二级标题` 分小节，每小节 1~2 个高频概念，配「定义 + 数字 + 一个例子」
4. **易混淆点 / 常见坑**：固定用「误区 vs 正确」对照表格，每个模块 3~6 条
5. **一页速查**（L3）：模块末尾固定 `## 📋 一页速查`，表格形式「问题 | 答案」，控制在 8~12 行内，只放最高频内容

## 6. mermaid 使用规范

- **何时用图**：流程（管理路径、评估流程）、层级关系（模块依赖）、决策分支（风险判断）用 `flowchart TB/LR`；对比与数值一律用表格，**不要**把表格内容画成图
- **样式**：沿用项目既有配色：

```
style A fill:#e3f2fd   # 根节点（蓝）
style B fill:#fff3e0   # 分支（橙）
style C fill:#e8f5e9   # 分支（绿）
style D fill:#f3e5f5   # 分支（紫）
style E fill:#ffebee   # 警示/风险（红）
```

- **节点文字**：简短名词（4~8 字），复杂说明放正文，图中不堆砌文字
- **每模块 2~4 张图**，避免过度图形化导致信息密度下降
- 语法检查：mermaid 节点标签含中文/括号时加引号，如 `A["体检报告解读"]`；subgraph 内引用用 `&` 连接

## 7. 表格与速查规范

- 数值型内容（血压、血糖、BMI、营养素比例、量表分界值）必须给**数字 + 单位 + 人群**（男/女/老年），不写"正常范围"这种模糊表述
- 目标值类表格列固定为：`指标 | 目标值 | 临界/预警 | 处理`
- 量表类表格列固定为：`量表 | 用途 | 分界值 | 注意`
- 「误区 vs 正确」表格列固定为：`误区 | 正确做法`

## 8. 风格对齐（必须遵守）

- 文件头 frontmatter：仅 `title` + `description` 两个字段（与项目既有 `healthcare/02-*.md`、`public-health/00-overview.md` 一致），不加 date/tags
- 一级标题 = 文件名中文标题；首行 `>` 引用块写一句「费曼式」大白话总结
- 一级模块标题用 `## 一、二、三`；二级用 `### 1.1 1.2`
- 章节间用 `---` 分隔
- 每模块正文控制在 **250~400 行**（含 mermaid 代码），宁可精简不要注水
- 末尾「推荐阅读」给 3~5 本，标注出版社（人民卫生出版社优先）
- 链接使用相对路径（如 `../chronic-disease/index.md`），跨模块引用用表格放在「相关链接」段

## 9. 内容来源与准确性约束

- 考试知识点以人民卫生出版社《健康管理师》（三级）教材与考试公告口径为准；数字类内容（目标值、分界值）必须与教材/指南一致，不确定时标注「以最新指南为准」
- 涉及「医疗行为边界」的内容（10、11 模块），口径保守：能做 = 评估/建议/随访；不能做 = 诊断/处方/治疗决策，并在表中明确
- 法规引用到**法律名称 + 条款要旨**即可，不全文引用；食品宣传合规以《食品安全法》《广告法》为底
- 不得编造具体补贴金额、报名费用、通过率等政策数字，涉及处写「以当地公告为准」
