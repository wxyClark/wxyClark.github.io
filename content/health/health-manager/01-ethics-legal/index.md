# 职业道德与法规

> **费曼学习法**：这个模块考的是"什么话不能说、什么事不能做"——职业伦理的底线题，背几组对照就够。

解决「哪些行为是健康管理师的职业红线」。**优先级 ★（官方权重 5%）**：考点密度低，但以判断/单选形式必考，靠速记拿分。

## 二、一页速查

| 问题 | 答案 |
|------|------|
| 健康管理师三大职业伦理 | 保密、知情同意、不伤害（客观公正） |
| 健康信息属于 | 敏感个人信息，须单独同意 |
| 保健品标签必写 | "本品不能代替药物" |
| 保健食品宣传禁止 | 宣称疾病预防/治疗功能 |
| 甲类传染病 | 鼠疫、霍乱（按甲类管理） |
| 能调整客户降压药吗 | 不能，建议遵医嘱并联系医师 |
| 非医师从事诊疗 | 违反《医师法》 |
| 体检结果直接告诉家属 | 须先告知本人并同意 |
