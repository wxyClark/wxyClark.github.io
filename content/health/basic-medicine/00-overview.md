## 📋 一页速查：身体最常用的几个数

| 问题 | 答案 |
|------|------|
| 人体九大系统 | 循环、呼吸、消化、泌尿、神经、内分泌、免疫、运动、生殖 |
| 生命体征四项 | 体温 36–37℃、脉搏 60–100 次/分、呼吸 12–20 次/分、血压 <120/80 mmHg |
| 血液四种成分 | 红细胞携氧、白细胞免疫、血小板凝血、血浆运输 |
| 四大基本组织 | 上皮、结缔、肌肉、神经 |
| 稳态怎么维持 | 以负反馈为主（血糖、体温、血压） |
| 体检血常规看什么 | 感染（白细胞）、贫血（血红蛋白）、凝血（血小板） |
| 疼痛的意义 | 是信号不是病，先找原因再止痛 |

> **看体检报告的最小方法**：先看参考区间，再看“偏离了多少”，最后看“是否与症状对应”。
